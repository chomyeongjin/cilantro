# 비타민 B 수집 기록 — 2026-09-20

10개 처방을 저장했다. 복합제 4개(NOW B-50 정제, Solgar B-Complex 100 식물성 캡슐,
Life Extension BioActive Complete B-Complex, Thorne Basic B Complex),
단일 B군 중심 6개(NOW B1, B2, B6, 나이아신아미드, B12, 비오틴)다.
B12에는 엽산도 포함되므로 순수 단일성분제는 아니다.

## 실제 작업 방식

1. 검색 색인에 노출된 쿠팡 상품/목록에서 판매 이력을 확인했다. 쿠팡 차단을 우회하지 않았다.
2. 제조사 공식 페이지의 Supplement Facts, 1회 섭취량과 주의사항을 읽었다.
3. 브랜드·처방·함량·제형을 기준으로 중복을 제거했다. 병당 캡슐 수와 묶음 수량은 무시했다.
4. 원문 발췌와 공식 URL, 확인일을 성분의 evidence에 연결했다. AI API/GMS 호출은 사용하지 않았다.
5. `seed_vitamin_b_batch.py`가 검증 후 기존 SQLite 등록/검토/공개 절차로 저장한다.
   같은 스크립트를 반복해도 동일 처방의 제품 수는 증가하지 않는다.

## 데이터 해석과 한계

- 미국 제조사 공식 라벨 기준이다. 쿠팡 판매분의 배치/라벨 버전까지 동일하다고 확정하지 않았다.
- 실시간 재고·가격은 확인하지 않았다. 일부 구매 링크는 쿠팡 상품 상세가 아닌 목록이다.
- 사진은 공식 대표 포장으로 판매 옵션의 정수/병수와 다를 수 있다.
- 모든 함량은 1회 섭취량 기준이다. Life Extension은 2캡슐, 나머지는 1정/캡슐/로젠지 기준이다.
- DFE/NE는 일반 질량과 같지 않아 mg로 환산하지 않는다.
- Thorne B3는 niacin 10mg + niacinamide 130mg = 140mg로 합산했으며 근거에 양쪽을 남겼다.
- 크기·하루 섭취 횟수·개별 성분 부작용은 추정하지 않는다. 미확인은 안전함을 뜻하지 않는다.
- 기능/for는 제조사 문구의 요약이지 개인별 섭취 권장이나 국내 기능성 승인 판정이 아니다.
- 이미지의 공개 서비스 재배포 권한은 별도 확인이 필요하다.

각 제품의 공식 URL과 쿠팡 확인 링크는 스크립트의 PRODUCTS와 DB sources/provenance에 있다.
공식 원문 발췌는 표의 공백/줄바꿈과 각주 표시를 정리한 검토 전사이며 페이지 전체 원본은 아니다.

## 재실행

저장소 루트에서 `.\.venv\Scripts\python.exe -X utf8 backend\seed_vitamin_b_batch.py` 실행.
