## 검토와 저장 방식

- 공개 검색 색인의 쿠팡 판매 흔적과 제조사 공식 제품 페이지를 대조했다. 쿠팡 직접 대량 크롤링 성공이나 현재 재고 확인을 의미하지 않는다.
- 원천 URL, 라벨의 1회 섭취량과 함량, 짧은 근거 인용, 제품 이미지 URL은 `catalog_expansion_review.json`에 저장했다.
- 포장 수량만 다른 제품은 제외한다. 브랜드·배합·함량·제형이 다른 제품은 구분한다. 이미 게시된 공식 URL/ID는 재수입하지 않는다.
- 원소 마그네슘과 마그네슘 화합물 중량, 엽산 DFE, CFU, EPA/DHA와 어유 총량을 구분했다.
- 제조 시점 CFU와 유통기한까지 보장되는 CFU는 동일하게 취급하지 않는다. 관련 내용은 제품별 potencyNote에 기록했다.
- 제조사 사진이므로 판매 패키지와 다를 수 있다. imageVerified는 조사 도구의 이미지 응답 확인 여부이며 전 이미지 브라우저 로딩 검증은 아니다.
- 성분 크기 다이어그램은 기존 표시 로직을 사용한다. 공식 근거 없는 효능·부작용·실측 알약 크기는 생성하지 않는다.
- 기존 성분별 태깅 규칙을 유지한다. 어린이용 이름만으로 KIDS 전체에 연결하지 않으며 연령 적합성은 별도 검토 대상이다.
- LLM/API를 사용하지 않았다. 판매분의 정확한 라벨·현재 재고·가격은 미확인이다.

## 재현

프로젝트 루트에서 `python backend/seed_catalog_expansion.py`는 검증만 한다.
`python backend/seed_catalog_expansion.py --publish`는 누락 제품만 게시한다.
동일 실행을 반복해도 기존 제품을 덮어쓰거나 중복 추가하지 않는다.

## 남은 작업
