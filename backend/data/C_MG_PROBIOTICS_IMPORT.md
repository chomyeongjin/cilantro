# 비타민 C·마그네슘·프로바이오틱스 수집 기록

확인일: 2026-09-20. 카테고리별 10종, 총 30종.

## 수집 방식

1. 쿠팡 공개 검색 색인에서 판매 이력이 있는 제품을 선정했다. 자동 접근이 제한된 페이지를 우회하지 않았다.
2. NOW Foods, Solgar, Doctor's Best, Life Extension, Jarrow 공식 제품 페이지의 성분표를 확인했다.
3. 공식 라벨 발췌, 출처 URL, 제품 사진 URL, 쿠팡 확인 링크를 `reviewed_c_mg_probiotics.json`에 저장했다.
4. 검토된 데이터를 `seed_c_mg_probiotics.py`로 기존 등록·분석·승인 흐름에 입력했다. LLM 추정값은 사용하지 않았다.
5. 수량·묶음 개수는 중복 기준에서 제외했다. 브랜드·배합·함량·제형이 다르면 별도 제품으로 취급했다.

## 함량 기준과 한계

- 함량은 공식 라벨의 1회 섭취 기준이며, 개인별 권장량이 아니다.
- 마그네슘은 화합물 중량이 아닌 원소량이다. NOW 말레이트 1000은 마그네슘 113mg, 마그테인은 144mg이다.
- 프로바이오틱스는 CFU로 저장한다. CFU를 mg나 구성비로 변환하지 않는다. 균주별 함량을 추정하지 않는다.
- Jarrow EPS 공식 현행 라벨은 2캡슐당 100억 CFU이다. 판매분 배치가 현행 공식 라벨과 같은지는 확인되지 않았다.
- CFU 보장 시점과 보관법은 해당 제품 페이지에서 확인된 내용만 보존했다. 냉장 제품은 냉장 보관을 표시한다.
- 크기 미확인 제품에는 실제 알약 크기나 사진을 만들어 넣지 않았다. 분말 제품도 캡슐로 취급하지 않는다.
- 현재 쿠팡 재고·가격·판매자·국내 유통 라벨은 미확인이다. 일부 구매 링크는 상품 상세가 아닌 검색/기획전이다.
- 제품 사진은 제조사 사이트 원본 URL을 사용한다. 외부 사이트 변경 시 깨질 수 있다.

## 검증

- 기존 제품 테스트 17개 및 수집 데이터 테스트 4개 통과.
- API에서 오메가3/비타민 B/C/마그네슘/프로바이오틱스 각각 10종 확인.
- 브라우저에서 신규 30개 제품 이미지 로딩 확인, 목록 및 프로바이오틱스 상세 함량 확인.
- 같은 스크립트를 재실행해도 고정 제품 ID/배합 키로 수량 중복을 생성하지 않는다.

재실행: `.venv/Scripts/python.exe backend/seed_c_mg_probiotics.py`
